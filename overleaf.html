Guia Prático do Overleaf

O Overleaf é um editor de LaTeX online e colaborativo que funciona diretamente no navegador, sem necessidade de instalar nada no computador.

💡 Principais Vantagens: Compilação automática em PDF, salvamento na nuvem, colaboração em tempo real e modelos prontos de artigos e teses.

1. Criando sua Conta

  1. Acesse o site oficial: overleaf.com.
  2. Clique em Register no canto superior direito.
  3. Você pode se cadastrar usando seu e-mail ou diretamente com sua conta Google/ORCID.

2. Modelos Acadêmicos Prontos (UTFPR)

Para facilitar a escrita de trabalhos acadêmicos, TCCs, dissertações e artigos no padrão institucional, utilize os modelos oficiais disponíveis:

🎓 Modelos TeX/LaTeX - UTFPR:
Acesse o repositório institucional com modelos preparados para uso direto no Overleaf:
👉 Clique aqui para acessar os Modelos TeX/LaTeX (UTFPR)

3. Criando um Projeto a partir de um Modelo

Após escolher ou baixar um modelo do repositório da universidade:

  • No Overleaf, clique no botão verde New Project.
  • Escolha Upload Project para carregar o arquivo .zip do modelo institucional.
  • O projeto abrirá automaticamente com toda a estrutura de pastas e pacotes configurados!

4. Conhecendo a Interface

A tela do Overleaf é dividida em 3 colunas principais:

  • Painel Esquerdo (Ficheiros): Lista de arquivos do projeto (como imagens, bibliografias e o arquivo principal main.tex).
  • Painel Central (Editor): Onde você digita o código LaTeX.
  • Painel Direito (Visualização): Mostra o PDF final gerado. Clique em Recompile (ou pressione Ctrl + Enter) para atualizar o PDF.

5. Baixando o PDF Final

Quando concluir o seu trabalho, basta clicar no ícone de Download PDF localizado logo acima da visualização do documento no painel direito.
