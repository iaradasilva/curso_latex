Passo a Passo: Criando seu Primeiro Documento Completo

Nesta aula prática, você irá montar um documento acadêmico estruturado (com capa, resumo, introdução, desenvolvimento e bibliografia) unindo tudo o que aprendeu nos módulos anteriores.

💡 Como praticar: Abra o Overleaf, crie um projeto em branco e copie o código-fonte de cada etapa abaixo no arquivo principal main.tex.

Passo 1: O Código-Fonte Principal (main.tex)

Este é o modelo completo unificado. Copie este bloco para o arquivo main.tex do seu projeto no Overleaf:

\documentclass[12pt, a4paper]{article}

% --- PACOTES BÁSICOS ---
\usepackage[utf8]{inputenc}    % Suporte para acentuação
\usepackage[brazil]{babel}     % Tradução automática (ex: "Contents" -> "Sumário")
\usepackage[margin=2.5cm]{geometry} % Configuração de margens
\usepackage{cite}              % Suporte a citações

% --- METADADOS DA CAPA ---
\title{\textbf{Título do Seu Trabalho: Subtítulo Explicativo}}
\author{Seu Nome Completo}
\date{\today}                   % Data automática

\begin{document}

% --- 1. CAPA ---
\maketitle
\thispagestyle{empty}          % Oculta o número da página na capa
\newpage

% --- 2. RESUMO ---
\pagenumbering{arabic}         % Inicia a numeração de páginas em números arábicos
\begin{abstract}
Este é o resumo do trabalho. Apresente aqui brevemente o objetivo da pesquisa, a metodologia empregada e os principais resultados obtidos.

\vspace{0.5cm}
\noindent \textbf{Palavras-chave:} LaTeX, Overleaf, Capa, Resumo, Bibliografia.
\end{abstract}

\newpage

% --- 3. CORPO DO TEXTO ---
\section{Introdução}
Esta é a introdução do documento. Para citar uma referência, usamos o comando \verb|\cite{chave}|. 

Por exemplo: segundo Lamport \cite{lamport1994latex}, o uso do LaTeX facilita a escrita técnica. Outro clássico da área é o trabalho de Knuth \cite{knuth1984texbook}.

\section{Desenvolvimento}
Aqui você pode organizar o conteúdo principal dividindo-o em seções e subseções.

% --- 4. REFERÊNCIAS BIBLIOGRÁFICAS ---
\bibliographystyle{plain}
\bibliography{referencias}

\end{document}

Passo 2: Criar o Arquivo de Bibliografia (referencias.bib)

Para que os comandos \cite{lamport1994latex} e \cite{knuth1984texbook} funcionem sem erro de compilação:

  1. No painel esquerdo do Overleaf, clique no ícone de Novo Arquivo (folha com o sinal de +).
  2. Nomeie o arquivo exatamente como referencias.bib e clique em Create.
  3. Cole o seguinte código dentro de referencias.bib:
@book{lamport1994latex,
  author    = {Leslie Lamport},
  title     = {LaTeX: A Document Preparation System},
  year      = {1994},
  publisher = {Addison-Wesley}
}

@book{knuth1984texbook,
  author    = {Donald E. Knuth},
  title     = {The TeXbook},
  year      = {1984},
  publisher = {Addison-Wesley}
}

Passo 3: Compilar e Gerar o PDF

Com os dois arquivos criados no projeto:

  • Clique no botão verde Recompile (ou pressione Ctrl + Enter).
  • O Overleaf irá gerar automaticamente a capa formatada, a página do resumo com as palavras-chave, as seções numeradas e a lista de referências ao final do documento.
