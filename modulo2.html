MÓDULO 2 • ESTILIZAÇÃO

Formatação de Texto e Seções

Neste módulo você aprenderá a estruturar hierarquicamente o seu documento e aplicar formatações tipográficas.

1. Seções e Subseções

O LaTeX gera automaticamente a numeração e o sumário a partir das tags de seção:

\section{Introdução}
\subsection{Contextualização}
\subsubsection{Detalhes Específicos}

\section*{Seção Não Numerada} % O asterisco remove a numeração

2. Estilos de Fonte

  • \textbf{Negrito} → Negrito
  • \textit{Itálico} → Itálico
  • \underline{Sublinhado} → Sublinhado
  • \texttt{Monoespaçado} → Código

3. Listas Organizadas

Para criar listas numeradas ou com marcadores:

% Lista com Marcadores
\begin{itemize}
    \item Primeiro item
    \item Segundo item
\end{itemize">

% Lista Numerada
\begin{enumerate}
    \item Primeiro passo
    \item Segundo passo
\end{enumerate}
